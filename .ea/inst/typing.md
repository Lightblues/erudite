# 两条通道
┌─────────────────────────┬───────────────────────────────────┬───────────────────────────────────────┐
│          通道           │             控制什么              │              API 走哪条               │

# macOS App 中的音频 API 层级
┌─────────────────────────────────────────────────────────┐

└───────────────────────────────────┬─────────────────────┘
                                    │
┌───────────────────────────────────┴─────────────────────┐
│ 中间层: AVFoundation                                     │

                                    │
